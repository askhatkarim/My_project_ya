# DataFrameReporter

`DataFrameReporter` — класс для первичной диагностики таблиц pandas. Он выводит количество строк и столбцов, количество и долю дубликатов, сводную статистику, а также количество и долю пропусков.

## Установка

Выполните команды в терминале из корня проекта. Если окружение `venv` уже создано, начните со второй команды.

```bash
python3.14 -m venv venv
source venv/bin/activate
python -m pip install -r requirements.txt
```

## Пример запуска

Скачайте `payments.csv` из материалов задания в Практикуме и положите его в папку `data/`. Если файл уже лежит по пути `data/payments.csv`, можно сразу запускать отчёт.

Откройте терминал в корне проекта и выполните команды:

```bash
source venv/bin/activate
python3 main.py
```

Скрипт выведет отчёт по платежам, включая размеры таблицы, дубликаты, сводную статистику и пропуски.
```

В отчёте будет 3 строки, 1 столбец, 1 дубликат и 1 пропуск.

Класс находится в `src/reporter.py`. Свои датасеты можно хранить в папке `data/`. Git игнорирует локальные файлы данных и папку виртуального окружения `venv/`.
